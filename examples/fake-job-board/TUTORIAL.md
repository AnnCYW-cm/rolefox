# 用合成岗位完成一次本地校准

本教程适用于 RoleFox `0.1.0-alpha.8`。Alpha.8 只增加七条 Playwright Chromium 自动浏览器流程、Node 静态 export harness、CI / 发布 E2E gate、Pages 部署后 smoke test 和失败报告；下文产品操作完整沿用 Alpha.7 的 Clear Signal / 明亮信号工作台与本地复核流程，没有新增或改变任何步骤。CSV/JSON 预览导入、重复检查、岗位编辑、搜索与六种筛选、感兴趣清单导出、评分、浏览器本地数据 schema、存储键和无外部动作的安全边界均保持不变，Alpha.1–Alpha.7 数据无需迁移。全部操作仍在当前浏览器完成；页面没有账号、云同步、后台扫描、岗位抓取、投递或回复功能。

Alpha.6 的历史说明保持不变：Alpha.6 将 Alpha.5 完整重做为 Fox Ledger，采用暖纸色、墨黑、克制的狐狸橙、线描台账式分割和连续岗位行，移除渐变图标、玻璃顶栏、胶囊堆叠、柔光阴影与多层圆角卡片。移动端在已有岗位时仍优先呈现结果，DOM、键盘与视觉顺序保持一致。该版本的操作能力、评分、浏览器本地数据 schema、存储键和安全边界均未改变，Alpha.1–Alpha.5 数据无需迁移；Alpha.5 保持为不可变的历史发布。

## 1. 打开 Alpha

打开已经发布的 RoleFox Alpha 页面，或在仓库根目录执行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

本地运行时访问 `http://localhost:3000`。如果浏览器阻止 `localStorage`，页面会锁定编辑，避免让你误以为数据已经保存。

## 2. 配置合成规则

打开 [`rules.json`](rules.json)，在“你想找什么”区域手工填写目标职位与目标地点，再展开“高级规则”填写关键词：

- 目标职位：`产品经理`
- 目标地点：`远程`
- 加分关键词：`AI，工作流，B2B`
- 硬排除关键词：`销售，区块链，Web3`

点击“保存并重新评分”。保存成功后高级规则会折叠，以便更快进入岗位与结果；规则文件目前不能直接上传，它只是可复制、可复查的示例。

## 3. 导入或粘贴岗位

推荐直接在岗位输入台选择 [`jobs.csv`](jobs.csv) 或 [`jobs.json`](jobs.json)，检查本地预览与重复状态后点击确认导入。也可以打开 [`jobs.paste.txt`](jobs.paste.txt) 并复制全部 12 行，展开“批量输入”，粘贴后点击“检查并导入”。

当前批量入口只接受以下格式之一：

```text
职位 | 公司 | 地点 | 描述
```

也可以用全角竖线或制表符分隔。批量粘贴一次最多读取 100 个非空行；单个 CSV/JSON 文件最多读取 500 条记录，当前浏览器总计最多保存 500 个岗位。CSV/JSON 文件只在当前浏览器读取，确认预览前不会写入岗位；“从备份恢复”仍只用于 RoleFox 完整状态备份，不能替代岗位导入入口。

## 4. 检查可解释结果

导入成功后应在连续结果列表中看到 12 个岗位。列表会按确定性分数排序，并分别显示命中的职位方向、地点、加分词和未命中的条件。

重点检查：

- “企业软件销售经理”应命中 `销售`，进入“已被硬规则排除”；
- “Web3 产品经理”应命中 `Web3` 与 `区块链`，进入“已被硬规则排除”；
- 地点、职位方向或加分词没有命中时只会显示关注项，不等同于硬排除；
- 分数是当前 Alpha 的规则排序结果，不是录用概率，也不会触发投递。

## 5. 做出校准选择

逐个选择“感兴趣”或“不感兴趣”。选择只记录在当前浏览器，用来比较规则分数与你的真实判断；再次点击相同选项可撤销。

建议至少检查一个高分岗位、一个低分岗位和两个硬排除岗位。如果排序与你的判断不一致，回到规则区域调整关键词并重新评分。

## 6. 导出或清除

在“管理本机数据”中：

- “导出完整备份”会下载规则、岗位正文和选择，文件可能包含敏感内容，请自行妥善保管；
- “导出无原文汇总”只包含数量、分数区间、选择统计和规则形态，不包含规则原文、公司、地点或岗位正文；
- “从备份恢复”只接受 RoleFox 自己生成且结构、版本均有效的完整导出；
- “清除当前浏览器数据”会永久移除本地记录，服务器没有副本可恢复。

请勿把真实简历、联系人、邮箱、聊天记录、凭证或岗位正文提交到公开 GitHub Issue。反馈只描述问题类型、预期行为，或附上本目录的合成样本。

## 示例数据的证据边界

本目录所有内容都是合成测试资料。完成本教程不代表通过真实用户研究、连接器验证、真实 Provider 验收或任何发布 Gate。Pre-W1 Gate 1 继续保持 `BLOCKED_NOT_STARTED`。
