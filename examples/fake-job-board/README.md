# 完全合成的岗位示例

本目录提供一组可公开使用的合成岗位，用于体验 RoleFox `0.1.0-alpha.2` 的浏览器本地岗位判断与偏好校准。样例随 `0.1.0-alpha.1` 首次公开发布，Alpha.2 只更新界面，沿用相同样例与能力边界。公司、职位和描述均为虚构内容，不对应真实招聘机会，也不能用于联系、申请或推断任何真实组织。

## 文件

- [`jobs.paste.txt`](jobs.paste.txt)：当前 Alpha 批量入口可以直接粘贴的格式。
- [`jobs.csv`](jobs.csv)：标准 CSV 形式，供阅读、表格处理和未来导入器测试使用。
- [`jobs.json`](jobs.json)：与当前岗位草稿字段一致的机器可读数组，供开发与测试使用。
- [`rules.json`](rules.json)：一组配套的合成偏好规则。
- [`TUTORIAL.md`](TUTORIAL.md)：从空白浏览器开始的完整操作教程。

## 当前限制

当前页面**没有 CSV 或岗位 JSON 文件导入器**。批量添加只接受每行一个岗位的文本，字段用半角竖线 `|`、全角竖线 `｜` 或制表符分隔：

```text
职位 | 公司 | 地点 | 描述
```

因此，请把 `jobs.paste.txt` 的内容粘贴到“批量粘贴”，不要把 `jobs.csv` 或 `jobs.json` 上传到“从备份恢复”。后者只接受 RoleFox 自己下载的完整本地状态文件，并会在覆盖前再次要求确认。

这些样本只验证界面和确定性规则行为，不是用户研究、真实岗位数据、连接器结果或任何发布 Gate 的证据。CI 不访问真实招聘平台。
