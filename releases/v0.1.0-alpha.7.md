# RoleFox v0.1.0-alpha.7

[中文](#中文) · [English](#english)

发布日期 / Release date: **2026-09-17**

## 中文

这是对 v0.1.0-alpha.6 的完整视觉与响应式界面重做。RoleFox 仍是浏览器本地运行的开源岗位判断与校准工具；本版将 Fox Ledger 重构为 **Clear Signal / 明亮信号工作台**，让工作区更清楚、更易扫读，同时不扩张任何产品能力。

### Clear Signal / 明亮信号工作台

- 以冷白、石墨和稀缺狐橙取代暖纸色与编辑台账式呈现，让狐橙只承担品牌和关键状态信号；
- 使用 64px 单层 app bar 统一品牌、任务导航与浏览器本地状态，减少首屏重复层级；
- 以连续结果账本和独立输入坞组织核心工作流，让查看、判断与录入保持清晰关系；
- 移除核心工作区的卡片堆叠与浮动阴影，改用留白、排版和克制分割表达结构；
- 移除超小字号并提高辅助信息的可读性，保留明确标签和渐进披露；
- 保留可见键盘焦点、主内容跳转、语义区域、读屏提示、弹窗焦点循环、Escape 取消、触发点焦点返回和 reduced-motion 行为。

仓库自动化检查继续覆盖文档、验证登记、lint、类型检查、静态构建、组件测试和 verification 测试。线上真实浏览器视口复核将在 Alpha.7 公开部署后继续完成，因此本说明不提前声明已经通过部署环境的视口验收。

### 兼容性与历史边界

业务能力、评分与排序、规则、合成样例、手工与批量岗位输入、校准选择、浏览器本地持久化、完整备份、无原文汇总、恢复、逐项删除、彻底清除和失败关闭行为均未改变。存储键、版本化数据 schema 和校验规则也没有变化；已有 Alpha.1–Alpha.6 本地数据无需迁移，仍可读取。

Alpha.7 沿用 Alpha.6 的安全边界，没有账号、服务端存储、云同步、自动抓取、真实平台连接、AI 调用、材料生成、自动投递、消息回复、邮箱或日历连接，也不会采取任何外部动作。

v0.1.0-alpha.6 作为已经发布的历史版本保持不可变。Alpha.7 不会追溯修改 Alpha.6 的标签、版本说明、Changelog 记录、验证制品或当时的范围陈述。

[在线体验](https://anncyw-cm.github.io/rolefox/)只需要现代浏览器，不需要注册账号。也可以跟随[合成样例教程](../examples/fake-job-board/TUTORIAL.md)完成一次本地校准。界面和仓库示例教程目前为中文。


本次界面重做没有新增产品能力，也没有改变浏览器本地数据 schema、存储键或安全边界。评分只反映本地规则，不预测岗位质量、录用概率或职业适配度。

## English

This is a complete visual and responsive-interface rebuild of v0.1.0-alpha.6. RoleFox remains an open-source, browser-local job-triage and calibration tool. This release rebuilds Fox Ledger as **Clear Signal**, making the workspace clearer and easier to scan without expanding any product capability.

### Clear Signal

- Replaced the warm-paper editorial treatment with cool white, graphite, and a scarce fox-orange accent, reserving orange for brand and critical state signals.
- Unified product identity, task navigation, and browser-local status in a single 64px app bar, reducing repeated first-screen hierarchy.
- Organized the core workflow around a continuous result ledger and a dedicated input dock so reviewing, deciding, and adding jobs remain clearly related.
- Removed stacked-card composition and floating shadows from the core workspace, using spacing, typography, and restrained rules to express structure.
- Removed ultra-small interface text and improved the readability of supporting information while preserving explicit labels and progressive disclosure.
- Preserved visible keyboard focus, skip navigation, semantic regions, screen-reader cues, modal focus cycling, Escape cancellation, trigger focus return, and reduced-motion behavior.

Repository automation continues to cover documentation, verification registry checks, linting, type checking, the static build, component tests, and verification tests. Live deployed-browser viewport review will continue after the public Alpha.7 deployment, so these notes do not prematurely claim that the deployed viewport review has passed.

### Compatibility and historical boundary

Product capabilities, scoring and ordering, rules, synthetic examples, manual and batch job input, calibration decisions, browser-local persistence, full backup, the no-text aggregate, restore, per-job deletion, full clearing, and fail-closed behavior are unchanged. The storage key, versioned data schema, and validation rules are also unchanged; existing Alpha.1–Alpha.6 local data require no migration and remain readable.

Alpha.7 keeps Alpha.6's safety boundary. It has no accounts, server storage, cloud sync, automatic scraping, real-platform connections, AI calls, material generation, automatic applications, message replies, mailbox access, or calendar access, and it takes no external actions.

v0.1.0-alpha.6 remains an immutable historical release. Alpha.7 does not retroactively alter the Alpha.6 tag, release notes, changelog record, verification artifacts, or scope statements published at that time.

The [live tool](https://anncyw-cm.github.io/rolefox/) needs only a modern browser and no account. You can also complete a local calibration with the [synthetic example tutorial](../examples/fake-job-board/TUTORIAL.md). The interface and repository example tutorial are currently in Chinese.

### Download and provenance

In addition to GitHub's source archives, the Release provides a `rolefox-web-v0.1.0-alpha.7.tar.gz` static build and its SHA-256 file. The release workflow accepts only a tagged commit contained in protected `main` history and produces a GitHub Actions OIDC provenance attestation for the static build.

With the [GitHub CLI](https://cli.github.com/) installed, verify the downloaded artifact from its directory:

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.7.tar.gz --repo AnnCYW-cm/rolefox
```

After extracting it, serve the directory with any static web server. For example, with Python 3 available locally:

```bash
tar -xzf rolefox-web-v0.1.0-alpha.7.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.7
```

### Capability and research boundary

This interface rebuild adds no product capabilities and changes neither the browser-local data schema, storage key, nor safety boundary. Scores represent local rules only; they do not predict job quality, hiring outcomes, or career fit.

Pre-W1 Gate 1 remains `BLOCKED_NOT_STARTED`. The Clear Signal rebuild, automated checks, publication, and synthetic data are not user-research evidence and change no verification state. Gate 1 decides only whether and how to begin the later productization W1; it does not block this narrowly scoped open-source release.

Report vulnerabilities privately as described in the [security policy](../SECURITY.md). This release uses the [Apache License 2.0](../LICENSE).
