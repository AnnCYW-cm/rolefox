# RoleFox v0.1.0-alpha.4

[中文](#中文) · [English](#english)

## 中文

这是对 v0.1.0-alpha.3 的完整视觉与响应式界面重做。RoleFox 仍是浏览器本地运行的开源岗位判断与校准工具；本版将 Quiet Workbench 重构为 **Signal Desk**，让界面拥有更清晰、鲜明且可辨认的产品性格，同时不扩张任何产品能力。

### Signal Desk

- 以冷石墨黑、雾白和电光狐橙替换 Alpha.3 的暖米色与暗橙色；酸绿和冷蓝只用于少量状态与辅助表面；
- 以几何负形狐狸 / `F` 标记替换卡通头像，并用硬边框、狐橙红线与单侧切角建立统一品牌语言；
- 使用编辑式 Masthead、深色设置栏和连续“机会排序”账本，桌面结果区占据主要工作面；
- 将加分词与硬排除词收进可展开的“高级规则”，并在保存后折叠；评分依据直接显示依据与留意项数量；
- 在移动端加入固定底部任务导航；有岗位时，结果在 DOM、键盘和视觉顺序中一致优先出现，空白态首个规则输入仍位于第一屏；
- 保持所有视口下的合成示例入口和至少 44px 的关键触控目标，修正弹窗关闭后的触发点焦点返回，并在确认删除后将焦点交给结果标题；
- 保留可见键盘焦点、主内容跳转、语义区域、读屏提示、弹窗焦点循环、Escape 取消和 reduced-motion 行为。

### 兼容性与历史边界

评分、排序、规则、合成样例、手工与批量岗位输入、校准选择、浏览器本地持久化、完整备份、无原文汇总、恢复、逐项删除、彻底清除和失败关闭行为均未改变。存储键、版本化数据 schema 和校验规则也没有变化；已有 Alpha.1–Alpha.3 本地数据不需要迁移，仍可读取。

Alpha.4 沿用 Alpha.3 的安全边界，没有账号、服务端存储、云同步、自动抓取、真实平台连接、AI 调用、材料生成、自动投递、消息回复、邮箱或日历连接，也不会采取任何外部动作。

v0.1.0-alpha.3 作为已经发布的历史版本保持不可变。Alpha.4 不会追溯修改 Alpha.3 的标签、版本说明、Changelog 记录、验证制品或当时的范围陈述。

[在线体验](https://anncyw-cm.github.io/rolefox/)只需要现代浏览器，不需要注册账号。也可以跟随[合成样例教程](../examples/fake-job-board/TUTORIAL.md)完成一次本地校准。界面和仓库示例教程目前为中文。


## English

This is a complete visual and responsive-interface rebuild of v0.1.0-alpha.3. RoleFox remains an open-source, browser-local job-triage and calibration tool. This release rebuilds the Quiet Workbench as **Signal Desk**, giving the interface a clearer, more distinctive product character without expanding any capability.

### Signal Desk

- Replaced Alpha.3's warm beige and muted orange with cool graphite, mist white, and electric fox orange; acid lime and cool blue are limited to small status and supporting surfaces.
- Replaced the cartoon mascot with a geometric negative-space fox / `F` mark, and established a consistent brand language through hard rules, fox-orange redlines, and one-sided clipped corners.
- Introduced an editorial masthead, a dark configuration rail, and a continuous opportunity ledger, with results occupying the primary desktop work surface.
- Moved preferred and hard-exclusion keywords into expandable advanced rules that collapse after saving; scoring details now expose reason and concern counts directly.
- Added fixed bottom task navigation on mobile. When jobs exist, results come first in matching DOM, keyboard, and visual order; in the empty state, the first rule input remains in the initial screen.
- Kept the synthetic-example action available at every viewport and restored at least 44px targets for key controls. Dialog cancellation returns focus to its trigger, while confirmed deletion moves focus to the results heading.
- Preserved visible keyboard focus, skip navigation, semantic regions, screen-reader cues, modal focus cycling, Escape cancellation, and reduced-motion behavior.

### Compatibility and historical boundary

Scoring, ordering, rules, synthetic examples, manual and batch job input, calibration decisions, browser-local persistence, full backup, the no-text aggregate, restore, per-job deletion, full clearing, and fail-closed behavior are unchanged. The storage key, versioned data schema, and validation rules are also unchanged; existing Alpha.1–Alpha.3 local data require no migration and remain readable.

Alpha.4 keeps Alpha.3's safety boundary. It has no accounts, server storage, cloud sync, automatic scraping, real-platform connections, AI calls, material generation, automatic applications, message replies, mailbox access, or calendar access, and it takes no external actions.

v0.1.0-alpha.3 remains an immutable historical release. Alpha.4 does not retroactively alter the Alpha.3 tag, release notes, changelog record, verification artifacts, or scope statements published at that time.

The [live tool](https://anncyw-cm.github.io/rolefox/) needs only a modern browser and no account. You can also complete a local calibration with the [synthetic example tutorial](../examples/fake-job-board/TUTORIAL.md). The interface and repository example tutorial are currently in Chinese.

### Download and provenance

In addition to GitHub's source archives, the Release provides a `rolefox-web-v0.1.0-alpha.4.tar.gz` static build and its SHA-256 file. The release workflow accepts only a tagged commit contained in protected `main` history and produces a GitHub Actions OIDC provenance attestation for the static build.

With the [GitHub CLI](https://cli.github.com/) installed, verify the downloaded artifact from its directory:

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.4.tar.gz --repo AnnCYW-cm/rolefox
```

After extracting it, serve the directory with any static web server. For example, with Python 3 available locally:

```bash
tar -xzf rolefox-web-v0.1.0-alpha.4.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.4
```

### Capability and research boundary

This interface rebuild adds no product capabilities and changes neither the browser-local data schema nor the safety boundary. Scores represent local rules only; they do not predict job quality, hiring outcomes, or career fit.

Pre-W1 Gate 1 remains `BLOCKED`. The Signal Desk rebuild, publication, and synthetic data are not user-research evidence and change no verification state. Gate 1 decides only whether and how to begin the later productization W1; it does not block this narrowly scoped open-source release.
