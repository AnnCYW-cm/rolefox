# RoleFox v0.1.0-alpha.3

[中文](#中文) · [English](#english)

## 中文

这是对 v0.1.0-alpha.2 的完整 UI 与信息架构重做。RoleFox 仍是浏览器本地运行的开源岗位判断与校准工具；本版将界面重构为 **Quiet Workbench**，让规则配置、岗位录入和排序结果成为页面主体，而不是继续扩展产品能力。

### Quiet Workbench

- 以暖灰白表面和狐橙品牌强调色替换 Alpha.2 的深色渐变与多重装饰效果，状态色只承担推荐、关注、排除和危险操作等语义；
- 以平直顶栏集中品牌、页面导航和本地存储状态，移除占据首屏的全高侧栏与大型宣传式 Hero；
- 在桌面上采用配置栏与连续结果列表的工作台结构，让筛选规则、岗位输入和可解释排序能并排工作；
- 将岗位结果从彼此悬浮的大卡片收敛为更紧凑、可连续扫描的列表，同时保留评分依据、人工校准和删除入口；
- 减少移动端首屏装饰和机械纵向堆叠，使核心任务更早出现，并保持清晰的触控尺寸和阅读顺序；
- 收敛圆角、阴影、渐变和非必要位移动效，继续保留可见键盘焦点、主内容跳转、语义区域、读屏提示以及弹窗焦点 / Escape 关闭行为。

### 兼容性与历史边界

评分、排序、规则、合成样例、手工与批量岗位输入、校准选择、浏览器本地持久化、完整备份、无原文汇总、恢复、逐项删除、彻底清除和失败关闭行为均未改变。存储键、版本化数据 schema 和校验规则也没有变化；已有 Alpha.1 与 Alpha.2 本地数据不需要迁移，仍可读取。

Alpha.3 沿用 Alpha.2 的安全边界，没有账号、服务端存储、云同步、自动抓取、真实平台连接、AI 调用、材料生成、自动投递、消息回复、邮箱或日历连接，也不会采取任何外部动作。

v0.1.0-alpha.2 作为已经发布的历史版本保持不可变。Alpha.3 不会追溯修改 Alpha.2 的标签、版本说明、Changelog 记录或当时的范围陈述。

[在线体验](https://anncyw-cm.github.io/rolefox/)只需要现代浏览器，不需要注册账号。也可以跟随[合成样例教程](../examples/fake-job-board/TUTORIAL.md)完成一次本地校准。界面和仓库示例教程目前为中文。

### 下载与来源验证

GitHub Release 除源码归档外，还提供 `rolefox-web-v0.1.0-alpha.3.tar.gz` 静态构建和对应的 SHA-256 文件。发布工作流只接受已进入受保护 `main` 历史的标签提交，并使用 GitHub Actions OIDC 为静态构建生成 provenance attestation。

安装 [GitHub CLI](https://cli.github.com/) 后，可在下载目录验证来源：

```bash

```

解压后可用任意静态 Web 服务器托管；例如本机有 Python 3 时：

```bash
tar -xzf rolefox-web-v0.1.0-alpha.3.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.3
```

### 能力与研究边界

本次完整界面重做没有新增产品能力，也没有改变浏览器本地数据 schema 或安全边界。评分只反映本地规则，不预测岗位质量、录用概率或职业适配度。

Pre-W1 Gate 1 保持 `BLOCKED`。Quiet Workbench 重做、上线事实与合成数据都不是用户研究证据，也没有改变任何验证状态；Gate 1 只用于决定是否、以及如何启动下一阶段产品化 W1，不阻止这一窄范围开源工具发布。

## English

This is a complete UI and information-architecture rebuild of v0.1.0-alpha.2. RoleFox remains an open-source, browser-local job-triage and calibration tool. This release rebuilds the interface as the **Quiet Workbench**, making rule configuration, job entry, and ranked results the center of the page instead of expanding product capabilities.

### Quiet Workbench

- Replaced Alpha.2's dark gradients and layered decoration with warm-gray-and-white surfaces and fox-orange brand accents; semantic colors are reserved for recommendation, review, exclusion, and destructive actions.
- Consolidated brand, page navigation, and local-storage status in a flat top bar, removing the full-height sidebar and oversized promotional hero that occupied the first screen.
- Introduced a desktop workbench with a configuration rail beside a continuous results list, allowing rules, job input, and explainable ordering to work side by side.
- Reworked job results from individually floating cards into a denser, continuously scannable list while retaining scoring details, human calibration, and deletion controls.
- Reduced first-screen decoration and mechanical vertical stacking on mobile so the core workflow appears sooner, while preserving clear touch targets and reading order.
- Reduced radii, shadows, gradients, and unnecessary movement while retaining visible keyboard focus, skip navigation, semantic regions, screen-reader cues, and dialog focus/Escape behavior.

### Compatibility and historical boundary

Scoring, ordering, rules, synthetic examples, manual and batch job input, calibration decisions, browser-local persistence, full backup, the no-text aggregate, restore, per-job deletion, full clearing, and fail-closed behavior are unchanged. The storage key, versioned data schema, and validation rules are also unchanged; existing Alpha.1 and Alpha.2 local data require no migration and remain readable.

Alpha.3 keeps Alpha.2's safety boundary. It has no accounts, server storage, cloud sync, automatic scraping, real-platform connections, AI calls, material generation, automatic applications, message replies, mailbox access, or calendar access, and it takes no external actions.

v0.1.0-alpha.2 remains an immutable historical release. Alpha.3 does not retroactively alter the Alpha.2 tag, release notes, changelog record, or scope statements published at that time.

The [live tool](https://anncyw-cm.github.io/rolefox/) needs only a modern browser and no account. You can also complete a local calibration with the [synthetic example tutorial](../examples/fake-job-board/TUTORIAL.md). The interface and repository example tutorial are currently in Chinese.

### Download and provenance

In addition to GitHub's source archives, the Release provides a `rolefox-web-v0.1.0-alpha.3.tar.gz` static build and its SHA-256 file. The release workflow accepts only a tagged commit contained in protected `main` history and produces a GitHub Actions OIDC provenance attestation for the static build.

With the [GitHub CLI](https://cli.github.com/) installed, verify the downloaded artifact from its directory:

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.3.tar.gz --repo AnnCYW-cm/rolefox
```

After extracting it, serve the directory with any static web server. For example, with Python 3 available locally:

```bash
tar -xzf rolefox-web-v0.1.0-alpha.3.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.3
```

### Capability and research boundary

This complete interface rebuild adds no product capabilities and changes neither the browser-local data schema nor the safety boundary. Scores represent local rules only; they do not predict job quality, hiring outcomes, or career fit.

Pre-W1 Gate 1 remains `BLOCKED`. The Quiet Workbench rebuild, publication, and synthetic data are not user-research evidence and change no verification state. Gate 1 decides only whether and how to begin the later productization W1; it does not block this narrowly scoped open-source release.

Use the [public Alpha feedback form](https://github.com/AnnCYW-cm/rolefox/issues/new?template=alpha-feedback.yml) for general experience reports, but do not submit real resumes, job descriptions, contacts, or other personal data. Report vulnerabilities privately as described in the [security policy](../SECURITY.md). This release uses the [Apache License 2.0](../LICENSE).
