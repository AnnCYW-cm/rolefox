# RoleFox v0.1.0-alpha.2

[中文](#中文) · [English](#english)

## 中文

这是 v0.1.0-alpha.1 首次公开发布后的界面更新。RoleFox 仍是浏览器本地运行的开源岗位判断与校准工具；本版只刷新视觉设计、信息架构、响应式布局和可访问性交互，没有新增产品能力。

### 本次变化

- 更新视觉系统、品牌图形、侧栏导航和响应式布局；
- 按“定义筛选偏好 → 添加岗位 → 校准排序”重排信息层级，并集中展示判断进度；
- 加强键盘焦点可见性、语义区域、读屏提示和移动端阅读顺序，并保留既有的主内容跳转与弹窗焦点 / Escape 关闭行为；
- 更准确地说明浏览器存储状态、完整备份、“无原文汇总”和 GitHub 公开反馈边界；
- 将源码、文档、许可和贡献入口集中到页尾。

评分、排序、规则、合成样例、岗位输入、校准选择、浏览器本地持久化、备份恢复和失败关闭行为均沿用 v0.1.0-alpha.1。存储数据结构没有变化，已有 Alpha.1 本地数据仍可读取。

[在线体验](https://anncyw-cm.github.io/rolefox/)只需要现代浏览器，不需要注册账号。也可以跟随[合成样例教程](../examples/fake-job-board/TUTORIAL.md)完成一次本地校准。界面和仓库示例教程目前为中文。

### 下载与来源验证

GitHub Release 除源码归档外，还提供 `rolefox-web-v0.1.0-alpha.2.tar.gz` 静态构建和对应的 SHA-256 文件。发布工作流只接受已进入受保护 `main` 历史的标签提交，并使用 GitHub Actions OIDC 为静态构建生成 provenance attestation。

安装 [GitHub CLI](https://cli.github.com/) 后，可在下载目录验证来源：

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.2.tar.gz --repo AnnCYW-cm/rolefox
```

解压后可用任意静态 Web 服务器托管；例如本机有 Python 3 时：

```bash
tar -xzf rolefox-web-v0.1.0-alpha.2.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.2
```

### 能力与研究边界

本版仍没有账号、服务端存储、云同步、自动抓取、真实平台连接、AI 调用、材料生成、自动投递、消息回复、邮箱或日历连接，也不会采取任何外部动作。评分只反映本地规则，不预测岗位质量、录用概率或职业适配度。

Pre-W1 Gate 1 保持 `BLOCKED`。本次 UI 更新、上线事实与合成数据都不是用户研究证据；Gate 1 只用于决定是否、以及如何启动下一阶段产品化 W1，不阻止这一窄范围开源工具发布。

一般体验问题可以使用[公开 Alpha 反馈表](https://github.com/AnnCYW-cm/rolefox/issues/new?template=alpha-feedback.yml)，但请勿提交真实简历、岗位正文、联系人或其他个人数据。安全问题请按[安全政策](../SECURITY.md)私下报告。本版使用 [Apache License 2.0](../LICENSE)。

## English

This is a UI follow-up to the first public release, v0.1.0-alpha.1. RoleFox remains an open-source, browser-local job-triage and calibration tool. This release refreshes only the visual design, information architecture, responsive layout, and accessibility interactions; it adds no product capabilities.

### What changed

- Refreshed the visual system, brand mark, sidebar navigation, and responsive layout.
- Reorganized the hierarchy around define preferences, add jobs, and calibrate the ranking, with a compact decision-progress summary.
- Improved visible keyboard focus, semantic regions, screen-reader cues, and mobile reading order while retaining the existing skip-navigation and dialog focus/Escape behavior.
- Clarified browser-storage status, full backups, the no-text aggregate, and the public nature of GitHub feedback.
- Consolidated source, documentation, license, and contribution links in the footer.

Scoring, ordering, rules, synthetic examples, job input, calibration decisions, browser-local persistence, backup and restore, and fail-closed behavior remain unchanged from v0.1.0-alpha.1. The stored-data structure is unchanged, so existing Alpha.1 local data remains readable.

The [live tool](https://anncyw-cm.github.io/rolefox/) needs only a modern browser and no account. You can also complete a local calibration with the [synthetic example tutorial](../examples/fake-job-board/TUTORIAL.md). The interface and repository example tutorial are currently in Chinese.

### Download and provenance

In addition to GitHub's source archives, the Release provides a `rolefox-web-v0.1.0-alpha.2.tar.gz` static build and its SHA-256 file. The release workflow accepts only a tagged commit contained in protected `main` history and produces a GitHub Actions OIDC provenance attestation for the static build.

With the [GitHub CLI](https://cli.github.com/) installed, verify the downloaded artifact from its directory:

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.2.tar.gz --repo AnnCYW-cm/rolefox
```

After extracting it, serve the directory with any static web server. For example, with Python 3 available locally:

```bash
tar -xzf rolefox-web-v0.1.0-alpha.2.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.2
```

### Capability and research boundary

This release still has no accounts, server storage, cloud sync, automatic scraping, real-platform connection, AI calls, material generation, automatic applications, message replies, mailbox access, or calendar access. It takes no external actions. Scores represent local rules only; they do not predict job quality, hiring outcomes, or career fit.

Pre-W1 Gate 1 remains `BLOCKED`. This UI update, publication, and synthetic data are not user-research evidence. Gate 1 decides only whether and how to begin the later productization W1; it does not block this narrowly scoped open-source release.

Use the [public Alpha feedback form](https://github.com/AnnCYW-cm/rolefox/issues/new?template=alpha-feedback.yml) for general experience reports, but do not submit real resumes, job descriptions, contacts, or other personal data. Report vulnerabilities privately as described in the [security policy](../SECURITY.md). This release uses the [Apache License 2.0](../LICENSE).
