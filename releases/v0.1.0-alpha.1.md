# RoleFox v0.1.0-alpha.1

[中文](#中文) · [English](#english)

## 中文

这是 RoleFox 的首个公开开源 Alpha。它是一个在浏览器本地运行的岗位判断与校准工具，不是求职 Autopilot。

### 现在可以做什么

- 设置目标职位、地点、加分词和硬排除词；
- 手工添加岗位，或按 `职位 | 公司 | 地点 | 描述` 批量粘贴；
- 查看确定性评分、排序、推荐理由、风险提示和硬排除结果；
- 标记感兴趣 / 不感兴趣，形成当前浏览器中的校准记录；
- 完整导出与恢复本地数据，导出匿名汇总，删除岗位或清除全部数据；
- 从内置示例或[仓库合成样例](../examples/fake-job-board/README.md)开始体验。

[在线体验](https://anncyw-cm.github.io/rolefox/)只需要现代浏览器，不需要注册账号。

### 下载与来源验证

GitHub Release 除源码归档外，还提供 `rolefox-web-v0.1.0-alpha.1.tar.gz` 静态构建和对应的 SHA-256 文件。发布工作流只接受已进入受保护 `main` 历史的标签提交，并使用 GitHub Actions OIDC 为静态构建生成 provenance attestation。

安装 [GitHub CLI](https://cli.github.com/) 后，可在下载目录验证来源：

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.1.tar.gz --repo AnnCYW-cm/rolefox
```

解压后可用任意静态 Web 服务器托管；例如本机有 Python 3 时：

```bash
tar -xzf rolefox-web-v0.1.0-alpha.1.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.1
```

### 当前边界

本版没有账号、服务端存储、云同步、自动抓取、真实平台连接、AI 调用、材料生成、自动投递、消息回复、邮箱或日历连接，也不会采取任何外部动作。评分只反映本地规则，不预测岗位质量、录用概率或职业适配度。

数据保存在当前浏览器；清除站点数据会删除记录。完整导出可能包含私人信息，请妥善保存。公开反馈只能使用合成或完全脱敏的数据。

### 验证状态

仓库检查、测试、静态构建和 GitHub Pages 部署用于验证这一窄范围 Alpha。Accepted Autopilot 设计中的 254 个 Case 仍是下一阶段基线，不能据此声称已实现。

Pre-W1 Gate 1 保持 `BLOCKED`，因为还没有真实用户研究证据。这不阻止本 Alpha 发布；Gate 1 只决定是否、以及如何开始下一阶段产品化工作。

## English

This is RoleFox's first public open-source Alpha. It is a browser-local job triage and calibration tool, not a job-search Autopilot.

### What works now

- Define a target role, location, preferred keywords, and hard exclusions.
- Add jobs manually or batch-paste `title | company | location | description` rows.
- Review deterministic scores, ordering, reasons, concerns, and hard exclusions.
- Record interested / not-interested decisions in the current browser.
- Export and restore a full local backup, export an anonymous aggregate, delete jobs, or clear all local data.
- Start with built-in examples or the repository's [synthetic examples](../examples/fake-job-board/README.md).

The [live tool](https://anncyw-cm.github.io/rolefox/) needs only a modern browser and no account.

The v0.1.0-alpha.1 interface and repository example tutorial are currently available in Chinese. The English README translates the main controls; an English interface is not included in this Alpha.

### Download and provenance

In addition to GitHub's source archives, the Release provides a `rolefox-web-v0.1.0-alpha.1.tar.gz` static build and its SHA-256 file. The release workflow accepts only a tagged commit contained in protected `main` history and produces a GitHub Actions OIDC provenance attestation for the static build.

With the [GitHub CLI](https://cli.github.com/) installed, verify the downloaded artifact from its directory:

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.1.tar.gz --repo AnnCYW-cm/rolefox
```

After extracting it, serve the directory with any static web server. For example, with Python 3 available locally:

```bash
tar -xzf rolefox-web-v0.1.0-alpha.1.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.1
```

### Current boundary

This release has no accounts, server storage, cloud sync, automatic scraping, real-platform connection, AI calls, material generation, automatic applications, message replies, mailbox access, or calendar access. It takes no external actions. Scores represent local rules only; they do not predict job quality, hiring outcomes, or career fit.

Data is stored in the current browser and disappears if site data is cleared. A full export may contain private information, so protect it accordingly. Public feedback must use synthetic or fully redacted data.

### Verification status

Repository checks, tests, static builds, and GitHub Pages deployment verify this narrow Alpha scope. The 254 cases in the accepted Autopilot design remain a next-phase baseline and are not implementation claims.

Pre-W1 Gate 1 remains `BLOCKED` because real-user research evidence does not yet exist. That does not block this Alpha release; Gate 1 decides only whether and how to begin the later productization work.
