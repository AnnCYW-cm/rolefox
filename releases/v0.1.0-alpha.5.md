# RoleFox v0.1.0-alpha.5

[中文](#中文) · [English](#english)

发布日期 / Release date: **2026-09-14**

## 中文

这是对 v0.1.0-alpha.4 的完整视觉与响应式界面重做。RoleFox 仍是浏览器本地运行的开源岗位判断与校准工具；本版将 Signal Desk 重构为 **Quiet Utility / Quiet Intelligence**，让界面回到安静、现代且以任务为中心的工具形态，同时不扩张任何产品能力。

### Quiet Utility / Quiet Intelligence

- 以统一浅色中性色和单一靛蓝强调替换 Alpha.4 的橙绿配色与黑色控制台表面；
- 以全无衬线字体、圆角、轻边框和更克制的层级替换宋体展示字、切角、硬分割线与厚重框线；
- 保持桌面配置区与结果区的清晰分工，同时收紧结果卡间距和信息密度，让岗位、公司、地点、理由与关注项更容易扫描；
- 将排名合并进分数块，在不改变任何分值或排序规则的前提下减少重复视觉元素；
- 移除固定移动底栏；有岗位时，结果仍在 DOM、键盘和视觉顺序中一致优先出现，空白态的首个规则输入仍位于第一屏；
- 保持关键按钮的安全触控目标，并让超长职位、公司、地点、理由与关注项在窄屏下安全换行；
- 保留可见键盘焦点、主内容跳转、语义区域、读屏提示、弹窗焦点循环、Escape 取消、触发点焦点返回和 reduced-motion 行为。

### 兼容性与历史边界

业务能力、评分与排序、规则、合成样例、手工与批量岗位输入、校准选择、浏览器本地持久化、完整备份、无原文汇总、恢复、逐项删除、彻底清除和失败关闭行为均未改变。存储键、版本化数据 schema 和校验规则也没有变化；已有 Alpha.1–Alpha.4 本地数据无需迁移，仍可读取。

Alpha.5 沿用 Alpha.4 的安全边界，没有账号、服务端存储、云同步、自动抓取、真实平台连接、AI 调用、材料生成、自动投递、消息回复、邮箱或日历连接，也不会采取任何外部动作。

v0.1.0-alpha.4 作为已经发布的历史版本保持不可变。Alpha.5 不会追溯修改 Alpha.4 的标签、版本说明、Changelog 记录、验证制品或当时的范围陈述。

[在线体验](https://anncyw-cm.github.io/rolefox/)只需要现代浏览器，不需要注册账号。也可以跟随[合成样例教程](../examples/fake-job-board/TUTORIAL.md)完成一次本地校准。界面和仓库示例教程目前为中文。

### 下载与来源验证

GitHub Release 除源码归档外，还提供 `rolefox-web-v0.1.0-alpha.5.tar.gz` 静态构建和对应的 SHA-256 文件。发布工作流只接受已进入受保护 `main` 历史的标签提交，并使用 GitHub Actions OIDC 为静态构建生成 provenance attestation。

安装 [GitHub CLI](https://cli.github.com/) 后，可在下载目录验证来源：


解压后可用任意静态 Web 服务器托管；例如本机有 Python 3 时：

```bash

python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.5
```

本次界面重做没有新增产品能力，也没有改变浏览器本地数据 schema、存储键或安全边界。评分只反映本地规则，不预测岗位质量、录用概率或职业适配度。

## English

This is a complete visual and responsive-interface rebuild of v0.1.0-alpha.4. RoleFox remains an open-source, browser-local job-triage and calibration tool. This release rebuilds Signal Desk as **Quiet Utility / Quiet Intelligence**, returning the interface to a calm, modern, task-focused utility without expanding any capability.

### Quiet Utility / Quiet Intelligence

- Replaced Alpha.4's orange-and-lime accents and black console surfaces with a unified light-neutral system and one indigo accent.
- Replaced serif display type, clipped corners, hard rules, and heavy frames with an all-sans-serif type stack, rounded surfaces, light borders, and restrained hierarchy.
- Preserved the clear division between desktop configuration and results while tightening result-card spacing and density so jobs, companies, locations, reasons, and concerns are easier to scan.
- Integrated rank into the score block, removing a repeated visual element without changing any score or ordering rule.
- Removed the fixed mobile bottom dock. When jobs exist, results still come first in matching DOM, keyboard, and visual order; in the empty state, the first rule input remains in the initial screen.
- Kept key button targets touch-safe and allowed long titles, companies, locations, reasons, and concerns to wrap safely at narrow widths.
- Preserved visible keyboard focus, skip navigation, semantic regions, screen-reader cues, modal focus cycling, Escape cancellation, trigger focus return, and reduced-motion behavior.

### Compatibility and historical boundary

Product capabilities, scoring and ordering, rules, synthetic examples, manual and batch job input, calibration decisions, browser-local persistence, full backup, the no-text aggregate, restore, per-job deletion, full clearing, and fail-closed behavior are unchanged. The storage key, versioned data schema, and validation rules are also unchanged; existing Alpha.1–Alpha.4 local data require no migration and remain readable.

Alpha.5 keeps Alpha.4's safety boundary. It has no accounts, server storage, cloud sync, automatic scraping, real-platform connections, AI calls, material generation, automatic applications, message replies, mailbox access, or calendar access, and it takes no external actions.

v0.1.0-alpha.4 remains an immutable historical release. Alpha.5 does not retroactively alter the Alpha.4 tag, release notes, changelog record, verification artifacts, or scope statements published at that time.

The [live tool](https://anncyw-cm.github.io/rolefox/) needs only a modern browser and no account. You can also complete a local calibration with the [synthetic example tutorial](../examples/fake-job-board/TUTORIAL.md). The interface and repository example tutorial are currently in Chinese.

### Download and provenance

In addition to GitHub's source archives, the Release provides a `rolefox-web-v0.1.0-alpha.5.tar.gz` static build and its SHA-256 file. The release workflow accepts only a tagged commit contained in protected `main` history and produces a GitHub Actions OIDC provenance attestation for the static build.

With the [GitHub CLI](https://cli.github.com/) installed, verify the downloaded artifact from its directory:

```bash
gh attestation verify rolefox-web-v0.1.0-alpha.5.tar.gz --repo AnnCYW-cm/rolefox
```

After extracting it, serve the directory with any static web server. For example, with Python 3 available locally:

```bash
tar -xzf rolefox-web-v0.1.0-alpha.5.tar.gz
python3 -m http.server 8000 --directory rolefox-web-v0.1.0-alpha.5
```

### Capability and research boundary

This interface rebuild adds no product capabilities and changes neither the browser-local data schema, storage key, nor safety boundary. Scores represent local rules only; they do not predict job quality, hiring outcomes, or career fit.

Pre-W1 Gate 1 remains `BLOCKED_NOT_STARTED`. The Quiet Utility / Quiet Intelligence rebuild, publication, and synthetic data are not user-research evidence and change no verification state. Gate 1 decides only whether and how to begin the later productization W1; it does not block this narrowly scoped open-source release.

Use the [public Alpha feedback form](https://github.com/AnnCYW-cm/rolefox/issues/new?template=alpha-feedback.yml) for general experience reports, but do not submit real resumes, job descriptions, contacts, or other personal data. Report vulnerabilities privately as described in the [security policy](../SECURITY.md). This release uses the [Apache License 2.0](../LICENSE).
