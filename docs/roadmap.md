# Roadmap

## M0 — Foundation

- [x] pnpm TypeScript monorepo
- [x] 领域模型与申请状态机
- [x] 自动化策略和 kill switch
- [x] 连接器能力协议
- [x] 演示看板
- [x] 开源治理与 CI 基线

## M1 — Find and rank

- [ ] 候选人画像与搜索规则
- [ ] 手动 URL 和 CSV 导入
- [ ] 首个公开招聘源适配器
- [ ] 岗位标准化、去重与过期检测
- [ ] 硬过滤、匹配评分与推荐解释
- [ ] 本地 SQLite 持久化

## M2 — Tailor and approve

- [ ] 履历事实证据库
- [ ] 定制简历、求职信和招呼语
- [ ] 材料版本差异与事实引用
- [ ] ActionPlan 预览和审批中心

## M3 — Controlled apply

- [ ] 本地 Playwright runner
- [ ] 模拟招聘站和连接器契约测试
- [ ] 自动填表和截图预览
- [ ] 一次性 approval token
- [ ] 幂等、限额、审计和全局停止开关

## M4 — Communicate and notify

- [ ] 邮箱和消息同步
- [ ] 问题分类与白名单答案库
- [ ] 回复草稿与有限自动回复
- [ ] 面试信息抽取、冲突检测和日历提醒
- [ ] 邮件、飞书和通用 Webhook 通知

## 暂不规划

- 无人监管的 L4 全自动模式
- 绕过平台安全机制
- 招聘方功能或候选人数据交易
