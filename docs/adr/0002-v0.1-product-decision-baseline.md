# ADR-0002：接受 v0.1 产品与目标设计基线

- 状态：Accepted
- 日期：2026-09-09
- 适用范围：RoleFox v0.1
- 决策来源：产品负责人分四组逐项确认
- 关联文档：[ADR-0001](0001-pre-interview-autopilot.md)、[v0.1 PRD](../product/prd-v0.1.md)、[UML 设计基线](../product/uml/README.md)、[Case 追踪矩阵](../product/uml/07-traceability.md)

## 背景

完整 P0 Case 与 UML 评审暴露了 19 项会直接改变范围、状态、授权、数据保留、故障恢复或 Connector 契约的产品选择。若这些选择保持开放，工程实现会被迫自行猜测默认值，并可能在通知、排期、恢复和数据治理等高风险路径产生互相矛盾的行为。

本 ADR 锁定 v0.1 的产品与目标设计基线。`Accepted` 表示这些约束已经可以作为开发输入；不表示当前 M0 已实现它们，也不表示相关测试或能力开放门已经通过。

| DEC-19 | ACCEPTED | 旧 ActionPlan 和授权永不自动复活。完成 reconcile 后由用户按 capability 恢复，首先进入 L2；通过健康检查并明确确认后才能重新进入 L3。 |
| DEC-20 | ACCEPTED | v0.1 只创建候选人私有日历事件，不添加招聘方 attendee，也不触发日历邀请邮件；确认只能通过已授权 Reply Connector。外部邀请以后作为独立授权能力设计。 |

除保留的 DEC-13 外，19 项决策全部接受。DEC 编号属于稳定审计标识，不因文案调整而改变或复用。

## 影响

- PRD、UML、追踪矩阵、验证计划、交付计划、架构和安全说明以本 ADR 为统一工程输入。
- 254 条 Case 的 `review_status` 统一为 `ACCEPTED`，只表示设计映射已接受；`implementation_status` 继续保持 `NOT_VERIFIED`，直到绑定测试并实际通过。
- v0.1 的正式持久化与兼容测试只覆盖 SQLite。`RES-003` 中 PostgreSQL pool 分支、`OSS-008` 的 SQLite↔PostgreSQL 迁移，以及其他 PostgreSQL/跨库测试在 v0.1 为未来范围/N/A，不阻断 SQLite 交付。
- 当前 M0 配置和策略代码仍把每日自动约面默认值设为 8，与 DEC-03 的目标默认值 3 不一致；这是实施差距，进入真实执行前必须修复并测试，本次设计接受不修改业务代码。
- BOSS 直聘 Connector、第二个必需外部备用通知渠道、跨账户日历聚合、AI 面试建议、日历外部邀请和 PostgreSQL 均不进入 v0.1 核心闭环。

## 变更控制

本 ADR 作为已接受基线保留历史原貌。后续若改变任一决策，应新增 ADR 并明确 `supersedes DEC-xx in ADR-0002`，同时更新 PRD、UML、追踪矩阵和验证门；不得静默改写本记录。
