# 产品边界

## 一句话定位

RoleFox 是一个本地优先、可审计、默认需要人工确认的 AI 求职助手。

## 首要用户

第一阶段服务正在主动求职、需要同时管理多个渠道与大量重复流程的个人用户。它优先解决“发现慢、筛选累、材料重复、跟进易漏”，而不是用海投掩盖岗位定位或简历转化问题。

## 核心任务

1. 持续发现符合搜索条件的新岗位。
2. 过滤明显不合适的岗位并解释推荐理由。
3. 基于真实履历事实准备定制材料。
4. 让用户在一个审批中心确认所有外部动作。
5. 跟踪沟通和面试，及时提醒并沉淀漏斗数据。

## MVP 不做

- 不支持无人监管的全平台批量海投。
- 不绕过验证码、登录限制或平台安全机制。
- 不代替用户进行薪资、Offer 或法律事项承诺。
- 不以 LLM 判断替代地点、薪资等确定性硬规则。
- 不构建招聘方筛选、候选人画像出售或数据经纪业务。

## 成功指标

- 每周节省的岗位搜索与材料准备时间
- 高匹配岗位被用户接受的比例
- 投递后获得有效回复的比例
- 有效回复到面试的转化率
- 错误投递、重复投递和未经批准操作数量（目标为 0）
