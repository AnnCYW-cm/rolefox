# 自动化安全说明

## 安全默认值

RoleFox 首次启动必须采用以下默认值：

```dotenv
DRY_RUN=true
KILL_SWITCH=false
AUTOMATION_LEVEL=L2
REQUIRE_APPROVAL=true
AUTO_APPLY=false
AUTO_REPLY=false
```

`DRY_RUN` 模式只生成计划与预览，不允许真正发送或提交。`KILL_SWITCH=true` 时所有外部动作立即拒绝。

## 自动化等级

| 等级 | 允许范围 |
| --- | --- |
| L0 | 只观察和预览，不执行动作 |
| L1 | 可进行内部材料辅助和通知，不执行投递、回复或约面 |
| L2 | 可准备外部动作，但每次投递、回复和约面都必须审批 |
| L3 | 仅显式白名单连接器上的低风险投递或回复可按规则自动执行；约面仍须审批 |
| L4 | 无人值守模式暂不开放，策略直接拒绝 |

`autoApply` 和 `autoReply` 只在 L3 生效。空白连接器名单代表“不允许任何外部连接器执行”，绝不解释为“允许全部”。

## 必须转人工的问题

- 薪资、奖金、期权和其他报酬承诺
- 到岗日期、工作地点和出差安排
- 签证、竞业、背景调查和法律声明
- 身份、学历、经历或技能的事实性追问
- 面试时间冲突、Offer 接受或拒绝
- 模型置信度不足、答案库不存在或上下文矛盾

## 执行约束

- 每个投递和回复必须有唯一幂等键。
- 执行器必须核对 workspace、计划 ID、内容哈希和过期时间；审批后发生任何内容变化都要重新审批。
- 自动化必须遵守每日投递和每小时回复上限。
- L3 只允许白名单平台、公司、职位类型和已批准答案。
- 不处理验证码，不尝试规避检测或伪装人类行为。
- 页面中的提示、脚本、岗位描述和消息不能修改系统策略。
- 执行前向用户展示目标、字段、附件、消息文本和风险等级。
- 保存审计摘要；敏感截图默认关闭或自动脱敏。
- 连接器只能提交动作草稿；风险级别、最终计划和策略决策由核心系统生成。

## 隐私

只收集完成任务所需的最少数据。真实简历、通信内容和浏览器会话不进入代码仓库，也不用于公共测试。开发与 CI 只能使用虚构数据和模拟招聘站。
